# AI Learning Radar 使用說明書（User Guide）

給一般使用者的完整操作指南。AI Learning Radar 每天從中文 YouTube AI 教學影片
中，挑出值得你投入時間的內容，並且先幫你整理好摘要、學習目標與小測驗。

- 適用版本：v1.0
- 介面語言：繁體中文
- 不需要註冊或登入，所有功能皆可匿名使用

---

## 1. 首頁：今日精選（Daily Top Picks）

開啟首頁，映入眼簾的就是**當日 Top 20** 精選教學影片：頂端是搜尋列與
主題切換按鈕，下方一行顯示今日主題、日期與更新狀態，接著是篩選列與
影片縮圖牆（桌機 4 欄、平板 2 欄、手機 1 欄），不需要捲動就能開始挑片。

### 1.0 亮色／暗色主題（Light / Dark Theme）

按右上角的太陽／月亮按鈕即可切換亮色與暗色主題。第一次進站會自動跟隨
你裝置的系統設定，切換後的選擇會記在瀏覽器（localStorage），下次進站
沿用。

### 1.1 每張卡片包含

| 區塊 | 說明 |
|---|---|
| 縮圖與排名 | 左上角 `#01`–`#20` 為當日名次；點縮圖進入詳情頁 |
| 頻道與發布日期 | 影片來源頻道與發布時間 |
| 觀看數 | 以繁中緊湊格式顯示，例如「3.8萬 次觀看」 |
| 參與度分數 | 見下方 1.2 的說明，例如「8.4%」 |
| 標籤（tags） | 影片的關鍵概念，例如 RAG、向量資料庫；入門影片會多一個綠色「入門」標籤 |
| 摘要 | 三行以內的短摘要 |
| 適合誰＋學習目標 | 這支影片適合什麼背景的人、看完能學到什麼 |
| 測驗數 | 「3 題小測驗」或「測驗準備中」 |
| YouTube ↗ | 開新分頁直接前往 YouTube 觀看 |
| 查看詳情 → | 進入站內詳情頁 |

### 1.2 「參與度分數」是什麼？

參與度分數（engagement score）＝ 按讚數 ÷ 觀看數。分數越高，代表看過的人
越願意按讚，通常表示內容品質與滿意度較高。預設排序還會再除以影片天數，
讓**新出、成長快**的好內容排得更前面。

### 1.3 篩選與排序（Filters）

首頁的篩選列可以組合以下條件，按「套用篩選」後生效：

| 篩選 | 選項 |
|---|---|
| 主題 | 所有 AI 主題 / RAG / AI Agent / 提示工程 / LLM |
| 難度 | 所有難度 / 入門 / 一般 |
| 語言 | 所有語言 / 繁體中文 / 簡體中文 / 英文 |
| 發布時間 | 不限 / 最近 7 天 / 30 天 / 90 天 |
| 內容類型 | 所有內容 / 影片 / 文章 |
| 排序 | 預設推薦 / 最新 / 最熱門 / 最適合入門 / 參與度分數 |

沒有符合條件的內容時會顯示空狀態提示，調整條件再試即可，不會出現錯誤頁。

## 2. 內容詳情頁（Content Detail）

點卡片標題、縮圖或「查看詳情」進入 `/content/<id>`，包含：

- **完整摘要**：影片講了什麼、怎麼講的。
- **學習目標**：條列看完後應具備的能力。
- **Transcript 摘要**：逐字稿層級涵蓋了哪些技術主題（英文關鍵字）。
- **限制與注意事項**：內容的適用邊界，避免誤用。
- **右側資訊欄**：頻道、發布日期、參與度分數、觀看數、按讚數、留言數、
  適合誰，以及「前往 YouTube ↗」按鈕。

## 3. 三題小測驗（Quiz）

每支處理完成的影片都附 **3 題單選測驗**，幫你確認有沒有真的看懂：

1. 每題從 A–D 選一個答案，三題都作答後才能按「送出答案」。
2. 送出後每個選項會直接標示「✓ 正確」或「✕ 你的選擇」，並附**解析**與
   **影片依據**（出自影片內容的原句）。
3. 可按「重新作答」再試一次。

> 隱私說明：作答完全匿名，答案只保留在你瀏覽器的頁面狀態中，
> **不會傳送或儲存到伺服器**。重新整理頁面即清空。

## 4. 搜尋（Search）

直接使用**頁面頂端的搜尋列**（任何頁面都有），或前往 `/search`：

- 輸入關鍵字（例如 `RAG`、`AI Agent`），可加上難度篩選。
- 搜尋範圍涵蓋：標題、頻道、摘要、標籤、學習目標與 transcript 摘要。
- 結果依發布時間排序。

---

## 5. 學習順序建議（Learning Path）

當搜尋結果 **達到 3 筆以上**，結果下方會出現「產生學習順序建議」按鈕：

1. 按下後系統只根據**這一頁的搜尋結果**規劃建議觀看順序。
2. 回傳內容包含：
   - 整體學習指引（含初學者注意事項）。
   - 建議觀看順序：每一項標明它扮演的角色（建立基本觀念 → 鞏固核心概念 →
     進階實作與整合）與推薦理由。
   - 下一步建議：例如完成測驗、用小型案例實作。

> 為了節省成本，建議不會自動產生，一定要你主動按按鈕才會計算。

## 6. 常見問題（FAQ）

**Q：需要帳號嗎？**
A：不需要。前台所有功能（瀏覽、篩選、搜尋、測驗、學習建議）都是匿名的。

**Q：為什麼有些影片顯示「測驗準備中」？**
A：該影片的分析流程尚未完成測驗生成，之後的每日更新會補上。

**Q：「入門」標籤是怎麼判斷的？**
A：由規則特徵（標題關鍵字、逐字稿用語）加上 LLM 分類綜合判斷，管理者
也可能人工修正。

**Q：頁面顯示「示範資料」是什麼意思？**
A：表示目前站台尚未連接正式資料庫，顯示的是內建範例內容，功能操作方式
與正式資料完全相同。

**Q：內容多久更新一次？**
A：每天執行一次自動蒐集與分析（daily digest），首頁的日期標示即當日精選。
